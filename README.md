## 📌 Featured Projects

### 🚗 Automotive EV Multi-ECU Simulator — STM32F407G, FreeRTOS, CAN
- Designed and developed the TCU module within a team-built multi-ECU simulator across 8 ECUs communicating over CAN at 500 kbps via TJA1050
- Implemented TCU with P/R/N/D/Sport gear FSM, joystick input (ADC + EXTI), and FreeRTOS task scheduler
- Designed Sport mode ICE generator activation and reverse speed cap at 30 km/h with torque cutoff; integrated ABS/airbag safety overrides via CAN
- Configured STM32 peripherals (CAN, ADC, EXTI, USART, GPIO) using STM32CubeMX and HAL drivers
- Validated the system using CanEasy for CAN frame analysis and UART debug logs

### 🔧 CAN Bus ECU Simulator — STM32, FreeRTOS, Embedded C
- Designed a dual-node CAN ECU simulator using STM32F407 for real-time Engine–Dashboard communication
- Configured CAN (500 kbps) using HAL, transmitting structured frames (RPM, temperature)
- Integrated FreeRTOS for communication, TFT display, and fault-handling tasks
- Implemented DTC-based fault injection with TFT visualization and buzzer alerts

### 🌍 Adaptive Environmental Monitoring and Alert Network — ESP32-S3
- IoT-based environmental monitoring system with real-time AQI tracking and multi-gas leakage detection
- Sends emergency alerts via GSM (SMS/Call)
- Uses mesh networking for area-wide air quality mapping
- Includes an inspection rover with camera for remote monitoring in hazardous and inaccessible environments
